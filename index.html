Edukasi Parameter Karhutla Standardisasi BMKG

Glosarium Indikator Sistem Peringatan Dini Kebakaran Hutan dan Lahan

Penjelasan istilah teknis berdasarkan pedoman resmi Fire Danger Rating System (FDRS) Badan Meteorologi, Klimatologi, dan Geofisika (BMKG).

FFMC

Fine Fuel Moisture Code

(Kode Kelembapan Bahan Bakar Halus): Tingkat kelembapan bahan bakar halus yang mudah terbakar seperti serasah, rumput kering, dan ranting di permukaan tanah. Mengindikasikan kemudahan penyalaan api pertama kali.

DMC

Duff Moisture Code

(Kode Kelembapan Bahan Organik Sedang): Tingkat kelembapan lapisan humus organik kedalaman sedang di bawah permukaan tanah. Menggambarkan kemudahan penjalaran api tingkat menengah.

DC

Drought Code

(Kode Kekeringan): Indikator kekeringan bahan organik tebal dan lapisan lahan gambut dalam. Menandakan potensi terjadinya kebakaran gambut dalam yang sulit dipadamkan.

FWI

Fire Weather Index

(Indeks Cuaca Kebakaran): Angka kombinasi dari parameter cuaca dan tingkat kelembapan bahan bakar. Menggambarkan potensi intensitas serta kecepatan penyebaran api secara keseluruhan.

IKLIM

Kesesuaian Iklim Titik Panas

Klasifikasi BMKG (Rendah, Menengah, Tinggi) yang mengukur sejauh mana variabilitas iklim (curah hujan, suhu, dan kelembapan udara) mendukung pembentukan titik panas (hotspot).

STATUS

Tingkat Kerawanan Wilayah

Kategori status risiko akhir (Aman, Waspada, Sangat Rawan) yang merepresentasikan tingkat potensi terjadinya kebakaran hutan dan lahan berdasarkan evaluasi terpadu FDRS.
